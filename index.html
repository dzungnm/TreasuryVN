Công cụ 1: Xử lý liệt kê ĐTKB

Hướng dẫn lấy dữ liệu trên hệ thống:
  • Vào mục Sổ sách/Báo cáo
  • Chọn 9.6. Sổ liệt kê chứng từ thanh toán vốn đầu tư
  • Chọn Trạng thái: Đã phê duyệt
  • Các thông số khác tùy ý
  • Sau đó ấn Tổng hợp
  • Chọn xuất file excel rồi gửi lên đây nhé
Chưa có file được xử lý. (Cột số tiền trên file tải về sẽ được định dạng dấu phân cách hàng nghìn #,##0).

Công cụ 2: Xử lý file tra cứu chứng từ

Hướng dẫn lấy dữ liệu trên hệ thống:
  • Vào mục Yêu cầu thanh toán
  • Chọn 8.11. Tra cứu chứng từ
  • Chọn Loại chứng từ (C301, C302, C205a, Chứng từ điều chỉnh)
  • Chọn Trạng thái: Đã phê duyệt
  • Các thông số khác tùy ý
  • Sau đó ấn Tìm kiếm rồi chọn In danh sách
  • Chọn xuất file excel rồi gửi lên đây nhé
Hỗ trợ chọn cùng lúc nhiều file Excel tra cứu chứng từ (C301, C302, C205a, Điều chỉnh...) để xử lý hàng loạt.
Bổ sung thông tin từ file tra cứu chứng từ tương ứng vào file liệt kê ĐTKB (4 sheet: C301, C302, C205a, DC)
File liệt kê có 4 sheet tương ứng với file chứng từ: tại sheet C301 và C302 của file liệt kê, khi thiếu dữ liệu ở Cột I, hệ thống đối chiếu mã trùng giữa Cột C (sheet C301, C302 file liệt kê) với Cột G (file tra cứu C301, C302 tương ứng) để đưa thông tin từ Cột J (file tra cứu C301, C302) vào Cột I sheet tương ứng trong file liệt kê.
Hệ thống tự động lưu dữ liệu tra cứu chứng từ theo từng loại sheet tương ứng (C301, C302, C205a, DC). Hãy xử lý Công cụ 1 (Liệt kê ĐTKB) và Công cụ 2 (Tra cứu chứng từ) rồi bấm bổ sung.
